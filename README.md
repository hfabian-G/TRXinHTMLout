# TRX Viewer

A Python script that parses `.trx` test result files (generated by `dotnet test`) and produces readable reports in both console and HTML formats.

## Features

- Parse TRX (Visual Studio Test Results) files
- Generate formatted console reports with test summaries
- Generate HTML reports with visual styling
- Display pass rates and test statistics
- Show detailed error messages for failed tests
- No external dependencies (uses Python standard library)

## Requirements

- Python 3.6 or higher
- No additional packages required

## Usage

### Console Report (default)

Display test results in the console:

```bash
python3 trx_viewer.py test-results.trx
```

Or make the script executable:

```bash
chmod +x trx_viewer.py
./trx_viewer.py test-results.trx
```

### HTML Report

Generate an HTML report with auto-generated filename:

```bash
python3 trx_viewer.py test-results.trx --html
```

Generate an HTML report with custom filename:

```bash
python3 trx_viewer.py test-results.trx --html my-report.html
```

### Help

View all available options:

```bash
python3 trx_viewer.py --help
```

## Generating TRX Files

To generate a `.trx` file from your .NET tests:

```bash
dotnet test --logger "trx;LogFileName=test-results.trx"
```

Or specify an output directory:

```bash
dotnet test --logger "trx" --results-directory ./TestResults
```

## How It Works

The script:
1. Parses the XML structure of the TRX file
2. Extracts test summary data (total, passed, failed, etc.)
3. Collects individual test results with durations and error messages
4. Formats the data into either console or HTML output
5. Calculates pass rates and highlights failed tests
