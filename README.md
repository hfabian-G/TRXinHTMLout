# TRX Viewer

A Python script that parses `.trx` test result files (generated by `dotnet test`) and produces readable reports in both console and HTML formats.

## Requirements

- Python 3.6 or higher
- No additional packages required

## Usage

### Console Report (default)

Display test results in the console:

```bash
python3 trx_viewer.py test-results.trx
```

### HTML Report

Generate an HTML report with auto-generated filename:

```bash
python3 trx_viewer.py test-results.trx --html
```

Generate an HTML report with custom filename:

```bash
python3 trx_viewer.py test-results.trx --html my-report.html
```

### Help

View all available options:

```bash
python3 trx_viewer.py --help
```
